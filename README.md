ehttpd
======

ehttpd is a small http server that is mainly developed to be a easy http implementation to small and embedded systems to provide access to text files.

* [Roadmap](ROADMAP.md) — project development plan from security fixes to HTTPS and HTTP/2.
* [HTTP/1.1 and HTTP/2](docs/http-protocols.md) — protocol concepts and implementation notes.
* [OpenSSL and HTTPS/TLS](docs/openssl-https.md) — TLS architecture and integration plan.
* [Implementation plan](docs/IMPLEMENTATION_PLAN.md) — detailed, task-by-task implementation instructions.
