ehttpd
======

ehttpd is a small http server that is mainly developed to be a easy http implementation to small and embedded systems to provide access to text files.

## Dokumentaatio (Documentation)

* [**HTTP/1.1 ja HTTP/2 -protokollat** (`http-protocols.md`)](./http-protocols.md) — Kuvaus HTTP/1.1- ja HTTP/2-protokollista, niiden eroista ja toteutuksesta `ehttpd`-palvelimessa.
* [**OpenSSL ja HTTPS/TLS-tuki** (`openssl-https.md`)](./openssl-https.md) — Kuvaus OpenSSL-kirjastosta, TLS-kättelystä, ALPN-neuvottelusta ja I/O-abstraktiokerroksesta.
* [**Kehityssuunnitelma / Roadmap** (`ROADMAP.md`)](./ROADMAP.md) — Vaiheittainen kehityssuunnitelma bugikorjauksista HTTPS- ja HTTP/2-tukeen.
* [**Tarkka toteutussuunnitelma** (`IMPLEMENTATION_PLAN.md`)](./IMPLEMENTATION_PLAN.md) — Yksityiskohtaiset tehtäväkohtaiset toteutusohjeet (suunniteltu esim. Gemini Flash -mallin suoritettavaksi).
